## 摘要
本文研究 Kleshchev 多重分拆，它们标记参数为 1 和 -1 的某些分圆 Hecke 代数的单模。2-剩余统计量将这些多重分拆划分为块。我们利用表示论推导出这些块的二元生成函数。我们还将固定块中多重分拆的生成函数与 Kac 和 Peterson 联系到 A_1^{(1)} 型仿射 Lie 代数的不可约最高权模的弦函数联系起来。通过考虑由这些生成函数构成的矩阵，我们利用 Rosengren--Schlosser 的 Macdonald 恒等式重新证明 Kac--Peterson 关于弦函数的一些结果。作为应用，我们得到这些生成函数的新无穷乘积公式。

## Abstract
In this paper we study the Kleshchev multipartitions that label simple modules of certain cyclotomic Hecke algebras with parameters $1$ and $-1$. The $2$-residue statistic divides these multipartitions into blocks. We deduce a bivariate generating function for the blocks using representation theory. We also relate the generating functions of multipartitions in a fixed block to string functions associated by Kac and Peterson to irreducible highest weight modules of a type $A_1^{(1)}$ affine Lie algebra. By considering matrices formed by these generating functions, we reprove some results of Kac--Peterson on string functions using the Macdonald identities of Rosengren--Schlosser. As an application, we obtain new infinite product formulas for these generating functions.
