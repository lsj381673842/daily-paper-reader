branching if it emits at least two distinct arrows. A vertex has access to another vertex if there is a directed path from the former to the latter, allowing paths of length zero. 

Main Theorem. Let K be a field, let Q be a nonempty quiver, and let C = KQ be its path coalgebra with dual algebra R = C∗. The following conditions are equivalent: 

(1) Every vertex of Q has access to a branching vertex. 

(2) R has no nonzero uniform right ideals.

The theorem is proved in Section 2. 1. Hollow Factors, Uniform Submodules, and Superdecomposable Modules 

A nonzero module M is called superdecomposable if it does not have nonzero indecomposable direct summands. A nonzero module is uniform if any two nonzero submodules have a nonzero intersection and it is called hollow if it cannot be written as the sum of two proper submodules. For a nonzero module M , its injective hull E(M ) is superdecomposable if and only if M contains no nonzero uniform submodules. Indeed, if D is an indecomposable direct summand of E(M ), then it is injective and hence uniform. Since M is essential in E(M ) and since nonzero submodules of uniform modules are uniform, D∩M is a nonzero uniform submodule of M . Conversely, if U is a nonzero uniform submodule of E(M ), then E(U ) is uniform. Since an injective module is uniform if and only if it is indecomposable, it follows that E(U ) is (isomorphic to) an indecomposable direct summand of E(M ) and E(M ) is not superdecomposable.

Recall that a vertex v of a quiver has access to another vertex v′ if there is a path p with 

s(p) = v and t(p) = v′. Now we are ready to prove the main theorem: 

Theorem 2.4. Let K be a field, Q a nonempty quiver, and C and R be its path coalgebra and convolution algebra, respectively. The following statements are equivalent: 

(1) Every vertex of Q has access to a branching vertex. 

(2) R has no nonzero uniform right ideals. 

(3) E(RR) is superdecomposable. 

(4) C has no nonzero hollow factor modules as a left R-module. Proof. (1) ⇒ (2) Let I be a nonzero right ideal of R. Take 0 ̸ = f ∈ I and let p be a path of minimal length such that f (p)̸ = 0.
