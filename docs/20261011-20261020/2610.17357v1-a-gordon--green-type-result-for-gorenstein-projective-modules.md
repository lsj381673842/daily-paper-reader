## 摘要
设 Λ 是一个 Z-分次 Artin 代数，且为 Iwanaga--Gorenstein。我们证明：Λ 是 CM-有限的当且仅当可分级 Gorenstein-投射模范畴具有有限型，且当且仅当不可分解的可分级 Gorenstein-投射模的长度有界。此外，若 Λ 是 CM-有限的，则每个 Gorenstein-投射 Λ-模都是可分级的。这些结果给出了 Gordon--Green 关于有限表示型分次 Artin 代数的相应定理的 Gorenstein-投射类比。

## Abstract
Let \(Λ\) be a \(\Z\)-graded Artin algebra which is Iwanaga--Gorenstein. We prove that \(Λ\) is CM-finite if and only if the category of gradable Gorenstein-projective modules has finite type, and if and only if the lengths of the indecomposable gradable Gorenstein-projective modules are bounded. Moreover, if \(Λ\) is CM-finite, then every Gorenstein-projective \(Λ\)-module is gradable. These results provide Gorenstein-projective analogues of the corresponding theorems of Gordon--Green for graded Artin algebras of finite representation type.
